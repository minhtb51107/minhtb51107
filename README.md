### 🚀 Selected work

**[🎯 Semi-Auto Video Tracking & Review](https://github.com/minhtb51107/semi_auto_video_tracking)** · `Python` `YOLO` `ByteTrack` `OpenCV` `CVAT`

A prototype that turns video-tracking outputs into reviewable quality flags. Tested tracking on video samples and a KITTI sequence; verified **20 CVAT review issues** in a sandbox, including duplicate-free retries. Documents false alerts and missed errors rather than treating predictions as ground truth.

**[🧩 Dataset Semantic Integrity Gate](https://github.com/minhtb51107/G4-C6-Dataset-Semantic-Integrity-Gate)** · `Python` `COCO` `Data Quality` · *Team project*

Contributed to a prototype for detecting silent semantic corruption in datasets that still pass syntax checks. Includes a controlled synthetic benchmark, stress tests, and an explicit **not-production-ready** decision with documented limitations.

**[🔎 ViBioMIR Biomedical Retrieval](https://github.com/minhtb51107/vibiomir_retrieval)** · `Python` `BGE-M3` `BM25` `RRF` `SQLite` · *Research / frozen*

A resource-constrained retrieval research pipeline with resumable data acquisition, hybrid candidate retrieval, reranking caches, and reproducible output validation. Explored retrieval behavior on **1,200 Vietnamese queries** and documented unsuccessful experiments and cross-lingual limitations.

**[🎬 TikTok / Shorts Automation](https://github.com/minhtb51107/Tiktok_Automation)** · `NestJS` `TypeScript` `Remotion` `AI APIs` · *Work in progress*

Developing modular workflows for content processing, speech/subtitles, and programmatic short-video generation. An evolving engineering prototype, **not a fully deployed autopublishing product**.

**Also from my software background:** [MindRevol backend — Java / Spring Boot](https://github.com/minhtb51107/mindrevol-backend).

### 🧭 How I approach engineering

```text
Understand the data → Build a baseline → Measure → Investigate failures
                                   ↓
                         Improve or document why not
```

I care about **clear evaluation, reproducible experiments, and honest limitations**. An interesting failure with solid evidence often teaches more than an impressive number without context.
